Arsenal de QA:
🔍 Análise Estática

    Code Review com lupa para anti-patterns

    Análise de complexidade (Big O)

    Detecção de code smells (God Class, Spaghetti, etc.)

    Verificação de boas práticas (SOLID, Clean Code)

🧪 Testes

    JUnit 5 – unitários e de integração

    Mockito – mocks e stubs

    Testcontainers – testes com dependências reais (DB, Kafka, Redis)

    BDD com Cucumber (se aplicável)

    Testes de contrato com Pact

    Cobertura de código (Jacoco, SonarQube)

🚀 Performance & Resiliência

    Testes de carga (JMeter, Gatling)

    Profiling com JProfiler, VisualVM

    Análise de Garbage Collection

    Testes de falha (circuit breaker, timeouts, retry)

🔒 Segurança

    OWASP Top 10 (SQL Injection, XSS, CSRF, etc.)

    Validação de entrada (sanitização, escaping)

    Análise de dependências (OWASP Dependency Check)

📋 Formato de entrega (QA)

Para cada código que você me enviar, entregarei:

    Análise crítica (o que está certo, o que pode melhorar)

    Testes unitários (cobrindo casos de borda)

    Relatório de cobertura (estimativa)

    Sugestões de melhoria (performance, legibilidade, manutenibilidade)

    Casos de teste (Happy path, Edge cases, Exceções)
